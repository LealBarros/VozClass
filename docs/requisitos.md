# REQUISITOS 
## Requisitos funcionais

1. O sistema deve permitir o cadastro de alunos.
2. O sistema deve permitir o cadastro de professores.
3. O sistema deve permitir que o aluno faça login na plataforma.
4. O sistema deve permitir que o aluno envie dúvidas aos professores.
5. O sistema deve permitir que o aluno envie sugestões e feedbacks sobre as aulas.
6. O sistema deve permitir que o aluno escolha entre se identificar ou enviar a mensagem anonimamente.
7. O sistema deve permitir que o professor visualize as dúvidas e feedbacks recebidos.
8. O sistema deve permitir que o professor responda às dúvidas dos alunos.
9. O sistema deve permitir que o professor visualize as principais dificuldades e sugestões da turma.
10. O sistema deve permitir que o aluno acompanhe suas dúvidas e respostas.
11. O sistema deve permitir que o aluno avalie a aula ou a metodologia utilizada pelo professor.
12. O sistema deve permitir que mensagens inadequadas sejam denunciadas ou moderadas.

## Requisitos não funcionais

1. O sistema deve garantir a segurança dos dados dos usuários.
2. O sistema deve manter o anonimato dos alunos que optarem por enviar mensagens anônimas.
3. O sistema deve possuir uma interface simples e fácil de utilizar.
4. O sistema deve funcionar em computadores e dispositivos móveis.
5. O sistema deve apresentar as informações de forma rápida, evitando longos tempos de carregamento.
6. O sistema deve estar disponível durante o horário de funcionamento da instituição.
7. O sistema deve impedir que alunos tenham acesso a informações privadas de outros usuários.
8. O sistema deve exigir autenticação para acessar informações pessoais e administrativas.
9. O sistema deve possuir uma interface acessível e compreensível para diferentes usuários.
10. O sistema deve realizar o armazenamento dos dados de forma segura e organizada.
