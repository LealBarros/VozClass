# Relatório de Validação e Testes - VozClass

## 1. Testes de Funcionalidade
- *Caso de Teste 01: Envio de Dúvidas*
  - *Entrada:* Pergunta digitada pelo aluno.
  - *Resultado Esperado:* Mensagem enviada com sucesso ao professor.
  - *Resultado Obtido:* Aprovado.

- *Caso de Teste 02: Resposta do Professor*
  - *Entrada:* Resposta enviada pelo painel docente.
  - *Resultado Esperado:* Exibição no painel do aluno.
  - *Resultado Obtido:* Aprovado.

## 2. Feedback dos Usuários
- *Estudante:* "Achei prático para tirar dúvidas sem vergonha."
- *Professor:* "Ajuda a organizar as perguntas mais frequentes das aulas."
